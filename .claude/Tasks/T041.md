# Task 41 – Verse label refinement and chapter-boundary markers in hover display

Status: **Next**
Issue: (pending — Designer proposal 2026-03-10)

## Goal

Implement D030: refine the verse label scheme so the first label in a multi-verse result shows
only the first-verse reference (e.g. `Gn 22,1` instead of `Gn 22,1-3`), and mark chapter
boundaries in cross-chapter results with a qualified label and a visual line break.

## Scope

### `src/provider.ts`

- Add `chapterBreak?: boolean` to the `VerseEntry` type.
- Refactor `addChapterVerses` to accept the current `chapter` number as a parameter.
- Change the first-entry label: call `formatRef` with a stripped ref (only `bookId`,
  `chapterStart`, `verseStart` — no `verseEnd`, no `chapterEnd`) instead of the full `ref`.
- For cross-chapter results, set `chapterBreak: true` on the first verse of every chapter
  after `chapterStart`. The label for those entries is chapter-qualified:
  `chapter + chapterVerseSeparator + verseNumber` (e.g. `2,1`), with no book abbreviation.
  Use `refFormat?.chapterVerseSeparator ?? BUILT_IN_FORMAT_RULES.chapterVerseSeparator`.

### `src/ui/verseDOM.ts`

- In `buildVerseDOM`, when appending an entry with `chapterBreak: true`, insert a `<br>`
  element instead of a space before the `<sup>` label.

### `docs/TESTPLAN.md`

- Add test cases for:
  - Single verse: label is `Gn 22,1` (unchanged).
  - Same-chapter range `Gn 22,1-3`: first label `Gn 22,1`; subsequent labels `2`, `3`.
  - Cross-chapter range `Gn 1,31-2,2`: labels `Gn 1,31`, `32`, then (new line) `2,1`, `2`.
  - Chapter-only ref `Gn 1`: first label `Gn 1,1` (first verse, not `Gn 1`).

## Definition of Done

- `getVerses` for a verse range returns the first entry with label = first-verse ref only
  (no range suffix).
- `getVerses` for a cross-chapter range sets `chapterBreak: true` and a chapter-qualified
  label on the first verse of each chapter after the first.
- `buildVerseDOM` renders a `<br>` before each chapter-boundary entry.
- No change to insert-command behaviour (`insertVerse.ts` uses `label` and `text` only —
  `chapterBreak` is irrelevant there; no modification needed).
- `npm run check` and `npm run ci` pass.
