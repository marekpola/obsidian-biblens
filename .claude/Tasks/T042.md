# Task 42 – Bundle English language pack and reference format pack on first install

Status: **Next**
Source: docs/SPEC.md § Bundled English Starter Pack

## Goal

Bundle the English recognition language pack (`recognition-languages/en.json`) and English
reference format pack (`reference-formats/en.json`) into `main.js` at build time via esbuild
JSON imports, and write them to the plugin directory on first install if they do not exist.

## Scope

- Add both JSON files as esbuild JSON imports in `esbuild.config.mjs` (or equivalent build entry).
- In `src/main.ts` `onload()`: for each bundled file, check if the target path exists via
  `this.app.vault.adapter`; if not, write the bundled data to disk.
  - `recognition-languages/en.json`
  - `reference-formats/en.json`
- Do not overwrite on subsequent loads — write only when the file is absent (deletion is intentional).
- After writing, the normal loaders (`languagePackLoader.ts`, `referenceFormatLoader.ts`) read
  them from disk as usual; no special-case path is needed.
- The auto-default mechanism in `settingsTab.ts` `display()` activates the packs when no preference
  is set — no changes needed there.
- Do not bundle or write `translations/en-web.json` in this task (see T043).
- Do not remove `BUILT_IN_FORMAT_RULES` or `getBuiltInAbbreviationMap()` in this task (see T044).
- Update `docs/TESTPLAN.md` with test steps for first-install write behaviour.

## Definition of Done

- `npm run ci` passes.
- On a clean install (neither file present), both JSON files are written to the plugin directory
  on first load and appear in their respective installed lists in settings.
- On subsequent loads, existing files are not overwritten.
- After deleting one file and reloading, only the deleted file is re… — actually: files are NOT
  recreated after deletion (deletion is intentional). Manual test confirms this.
- The auto-default mechanism sets both packs as active on first install without user action.
