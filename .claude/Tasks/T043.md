# Task 43 – Bundle WEB English translation on first install

Status: **Next**
Source: docs/SPEC.md § Bundled English Starter Pack

## Goal

Bundle the World English Bible translation (`translations/en-web.json`) into `main.js` at build
time via esbuild JSON import, and write it to the plugin directory on first install if it does
not exist.

## Pre-condition (must be resolved before this task goes Active)

The gzip-compressed size delta of adding the WEB translation to `main.js` must be measured and
verified to be ≤ 1 MB. If the delta exceeds 1 MB, this task is deferred and the Manager records
the finding; a smaller public-domain translation may be substituted.

To measure: build `main.js` with and without the WEB JSON import and compare gzip sizes.

## Scope

- Obtain a public-domain WEB translation file in BibLens v1 JSON format (verse keys
  `USFM_ID CHAPTER:VERSE`); validate it against the format defined in `docs/SPEC.md § Version 0.3`.
- Add the file as an esbuild JSON import.
- In `src/main.ts` `onload()`: if `translations/en-web.json` is absent, write from bundled data.
- Do not overwrite on subsequent loads.
- Add attribution entry for the World English Bible to `LICENSES.md`.
- Update `docs/TESTPLAN.md`.

## Definition of Done

- Bundle size delta measured and within the approved threshold.
- `npm run ci` passes.
- On clean install, `translations/en-web.json` is written and appears in the installed translations
  list; auto-default activates it if no preferred translation is set.
- On subsequent loads, the file is not overwritten.
- Deleted file is not recreated (deletion intentional).
- `LICENSES.md` contains WEB attribution.
