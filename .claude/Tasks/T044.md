# Task 44 – Remove built-in fallback constants BUILT_IN_FORMAT_RULES and getBuiltInAbbreviationMap

Status: **Next**
Source: docs/SPEC.md § Bundled English Starter Pack

## Goal

Remove the code-level constants `BUILT_IN_FORMAT_RULES` and `getBuiltInAbbreviationMap()` from
`src/books.ts` and update all callers, making the bundled JSON files the sole English defaults.
After this task, if no format pack or language pack is active, the plugin shows "None" in General
status rather than silently applying hardcoded English values.

## Pre-condition

T042 must be Done: the English language and format packs must be written to disk on first install
before the hardcoded fallbacks are removed.

## Scope

- Remove `BUILT_IN_FORMAT_RULES` export from `src/books.ts`.
- Remove `getBuiltInAbbreviationMap()` export from `src/books.ts`.
- Update `src/main.ts`: when `settings.standardReferenceFormat` is empty or the file is missing,
  pass `undefined` (no fallback) to `buildRefScanner` and `formatRef`; the scanner returns no
  matches when no format is active (existing no-op stub behaviour in `buildRefScanner`).
- Update `src/main.ts`: when `settings.preferredLanguage` is empty or the file is missing, pass
  an empty `AbbreviationMap` (no fallback); `buildRefScanner` returns the no-op stub.
- Update `src/parser.ts`: `buildRefScanner` already handles an empty map with a no-op stub —
  verify no reference to `BUILT_IN_FORMAT_RULES` remains.
- Update all other callers and imports of the removed exports.
- Update unit tests that relied on `BUILT_IN_FORMAT_RULES` or `getBuiltInAbbreviationMap()` as
  test fixtures — replace with inline test data or import from the bundled JSON.
- Update `docs/ARCHITECTURE.md` references to these constants.

## Definition of Done

- `npm run ci` passes with no references to the removed exports.
- With no language pack and no format pack active, the plugin loads without error; General status
  shows "None" for both; no references are detected in editor (scanner is no-op).
- With packs installed and active, behaviour is unchanged from before this task.
