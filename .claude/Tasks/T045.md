# Task 45 – Adapter listAvailable interface extension and biblens-data implementation

Status: **Done**
Source: docs/SPEC.md § Live Provider Item Discovery

## Goal

Add an optional `listAvailable?` method to all three adapter interfaces in
`src/sources/adapters.ts` and implement it for the `biblens-data` adapter, enabling
live discovery of available items from that provider.

## Scope

- In `src/sources/adapters.ts`, add an optional method to each interface:
  - `SourceAdapter`: `listAvailable?(provider: SourceProvider): Promise<RemoteTranslationEntry[]>`
  - `LanguagePackAdapter`: `listAvailable?(provider: LanguagePackProvider): Promise<RemoteLanguagePackEntry[]>`
  - `ReferenceFormatAdapter`: `listAvailable?(provider: ReferenceFormatProvider): Promise<RemoteReferenceFormatEntry[]>`
- Implement `listAvailable` for the `biblens-data` translation adapter: fetches
  `resources/translations/index.json` from the provider's `baseUrl`; parses the item list
  (shape: `{ items: { path: string; id: string; displayName: string; language: string }[] }`);
  returns `RemoteTranslationEntry[]`.
- Implement `listAvailable` for the `biblens-data` language pack adapter: fetches
  `resources/language-packs/index.json`; returns `RemoteLanguagePackEntry[]`.
- Implement `listAvailable` for the `biblens-data` reference format adapter: fetches
  `resources/reference-formats/index.json`; returns `RemoteReferenceFormatEntry[]`.
- `getbible-v2` and `beblia-xml` adapters do not implement `listAvailable` in this task.
- The `listAvailable` implementations in this task do not use `requestUrl` directly —
  callers (settingsTab, T046) will call them via `requestUrl` passed in, or the method
  signature accepts the raw fetch result. *(Decide during implementation: either the adapter
  method accepts a raw payload and the caller performs the network call, consistent with the
  existing `transform(raw)` pattern; or the method is async and performs the fetch itself using
  `requestUrl`. Prefer the former to keep `adapters.ts` free of Obsidian imports.)*
- Update `docs/ARCHITECTURE.md` adapter interface documentation to list the optional method.

## Definition of Done

- `npm run ci` passes.
- `biblens-data` adapters each have a working `listAvailable` method covered by a unit test
  (mock raw index payload → correct entry array).
- Other adapter types compile without errors (optional method absent — no type errors).
