# Task 47 – CM6 StateField/StateEffect live scanner propagation

Status: **Next**
Source: docs/SPEC.md § Settings Reactivity and Panel Conventions

## Goal

Replace the factory-closure pattern (scanner captured at registration time) with a CM6
`StateField<RefScanner>` + `StateEffect<RefScanner>` so that changing the active language pack,
reference format, or parsing rules updates all open editor views immediately without a plugin
reload. This supersedes T032's extension re-registration approach.

## Scope

- Create `src/editor/scannerState.ts` (new module):
  - Export `scannerEffect: StateEffect<RefScanner>` — used to push a new scanner into state.
  - Export `scannerField: StateField<RefScanner>` — holds the current scanner; initialised with
    a no-op stub; updated by `scannerEffect`.
- Update `src/editor/refDecorations.ts`:
  - `refDecorationsExtension()` no longer accepts a `scanner` parameter.
  - The `ViewPlugin` reads the active scanner from `view.state.field(scannerField)` on each
    update instead of from a closed-over variable.
- Update `src/editor/refTooltip.ts`:
  - `refTooltipExtension()` no longer accepts a `scanner` parameter (data and refFormat
    parameters unchanged).
  - Reads scanner from `state.field(scannerField)` inside the tooltip factory.
- Update `src/main.ts`:
  - Register `scannerField` as part of the editor extension array.
  - After `reloadScanner()` (called when settings change), dispatch `scannerEffect` with the new
    scanner on all open `MarkdownView` editors via `app.workspace.iterateAllLeaves`.
  - Remove the scanner parameter from `refDecorationsExtension()` and `refTooltipExtension()`
    call sites.
- Remove T032's re-registration logic (identify and delete the extension teardown + re-register
  pattern introduced by T032).
- Update `docs/ARCHITECTURE.md`: document `src/editor/scannerState.ts` module; update
  `refDecorationsExtension` and `refTooltipExtension` signatures; update module boundary table
  (`src/editor/scannerState.ts` may import `@codemirror/*`, must not import `obsidian`).

## Definition of Done

- `npm run ci` passes.
- Changing Parsing rules in settings updates reference highlights in open editors within one
  keystroke cycle — no plugin reload required (manual test).
- Changing the active reference format or language pack (Set as default) updates highlights
  immediately (manual test).
- No regressions: hover tooltips, insert commands, and Reading View hover still function
  correctly after the change.
