# Task 48 – Settings panel heading and spacing conventions

Status: **Done**
Source: docs/SPEC.md § Settings Reactivity and Panel Conventions

## Goal

Align settings panel section headings and spacing with Obsidian UI conventions: replace raw
`createEl('h3')` calls with `new Setting(el).setName(…).setHeading()` and replace inline
`style` spacing with a CSS class.

## Scope

- In `src/settingsTab.ts`: replace every `containerEl.createEl('h3', ...)` (or equivalent raw
  heading construction) with `new Setting(containerEl).setName('…').setHeading()`.
- Replace inline `style="margin-top: …"` (or similar) spacing between sections with a CSS class
  `biblens-section-spacer` applied via `addClass`.
- Add `.biblens-section-spacer` rule to `styles.css` (e.g. `margin-top: 2em;`).
- No functional changes; no settings values, save/load logic, or section content is altered.

## Definition of Done

- `npm run ci` passes.
- Settings tab renders with properly styled headings that respond to Obsidian theme changes
  (manual test with default theme and one community theme).
- No inline `style` attributes remain on spacing elements in the settings tab.
- All section headings use the Obsidian `Setting.setHeading()` pattern.
