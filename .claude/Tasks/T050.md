# Task 50 – Fix write-once flag for bundled starter packs

Status: **Next**
Source: docs/SPEC.md § Bundled English Starter Pack

## Goal

Replace the current file-existence check in `writeStarterPackIfAbsent` with a write-once flag
stored in plugin data. Once a bundled file has been written, the flag is set permanently —
the plugin never recreates it regardless of whether the file still exists on disk.
This means a user who intentionally deletes a bundled pack (translation, language pack,
format pack) will not see it reappear on the next plugin load.

## Scope

### Problem

`writeStarterPackIfAbsent` in `main.ts` calls `adapter.exists()` and writes only if the file
is absent. A deleted file is therefore recreated on every reload — contradicting the SPEC's
write-once flag design.

### Changes

- **`src/settings.ts`**
  - Add `bundledPacksWritten: Record<string, boolean>` to `BibLensSettings` interface
  - Add `bundledPacksWritten: {}` to `DEFAULT_SETTINGS`

- **`docs/ARCHITECTURE.md`**
  - Add `bundledPacksWritten: Record<string, boolean>` to the `settings.ts` module description field list

- **`src/main.ts`**
  - Replace `writeStarterPackIfAbsent(relativePath, data)` implementation:
    - Check `this.settings.bundledPacksWritten[relativePath]`; if truthy, skip (do not write)
    - If falsy: write the file (mkdir + adapter.write), then set
      `this.settings.bundledPacksWritten[relativePath] = true` and save settings
  - No change to call sites — the three starter pack write calls remain as-is

### Migration note

Existing users who have never deleted a bundled file: the flag will be absent on first load
after the update, the file already exists on disk, the write is attempted (idempotent — same
content), and the flag is set. From then on the file is treated as write-once.

Existing users who deleted a bundled file before this fix: the file will be recreated once
(on the first load after the update), then the flag is set and the file is treated as
write-once going forward. This is acceptable one-time behaviour.

## Definition of Done

1. Deleting `recognition-languages/en.json`, `reference-formats/en.json`, or
   `translations/en-web.json` and reloading the plugin does **not** recreate the file
2. `bundledPacksWritten` is persisted in plugin data (visible via `loadData()`)
3. `npm run ci` passes
4. Plugin builds successfully
