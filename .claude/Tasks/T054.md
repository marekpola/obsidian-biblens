# Task 54 – Translation priority/abbreviation: settings UI

Status: **Next**
Source: docs/SPEC.md § Translation Display Priority and Abbreviation Settings
Decision: docs/DECISIONS.md § D032

## Goal

Update the **Installed translations** list in Settings: add an abbreviation text field and a priority dropdown per row, implement drag-and-drop reordering, and remove the "Set as default" button.

## Scope

- `src/settingsTab.ts` — `renderInstalledTranslations(translations)`:
  - **Remove** the "Set as default" button from every translation row.
  - **Row layout** (left to right): `[abbreviation field] [priority dropdown] [Delete button]`
  - **Abbreviation text field**: pre-filled from `settings.translationAbbreviations[id]` (fallback to `id`). Visually flag (e.g. CSS class `biblens-abbr-over-limit`) when the entered value exceeds 3 characters — do not reject input beyond 3 characters. On change: update `settings.translationAbbreviations[id]`, save.
  - **Priority dropdown**: options `1 … n` (where `n` = number of installed translations) plus `-`. Current value from `settings.translationOrder[id]` (null or absent → `-`). On change:
    1. Renumber other entries so the sequence remains contiguous `1, 2, 3, …` with no gaps (shift existing priorities to accommodate the new assignment).
    2. Re-render the section with rows sorted: numbered rows at top in ascending priority order, `-` rows below.
    3. Save settings and call `this.plugin.reloadAllTranslations()`.
  - **Drag-and-drop**: set `draggable="true"` on each translation row `<div>`. Attach `dragstart`, `dragover`, and `drop` handlers using native DOM `addEventListener` directly on the transient row elements (not `this.registerDomEvent` — these elements are created and destroyed by `display()`, so they do not require plugin-lifecycle cleanup). On drop: reassign priority numbers to match the new visual order; `-` rows dragged above numbered rows receive the next available number; numbered rows dragged below `-` rows become `-`. Save settings and re-render section.

Out of scope: Multi-translation loading (T055), insert command changes (T057).

## Definition of Done

- `npm run ci` passes.
- Abbreviation field pre-filled with `id` on first install; changes persist across plugin reload.
- Priority dropdown renumbers correctly when any entry changes; list re-renders in priority order.
- Drag-and-drop reorders rows and updates priority numbers accordingly.
- "Set as default" button absent from all translation rows.
- `-` translations always appear below all numbered translations after any reorder or change.
- Visually flagged when abbreviation field value exceeds 3 characters.
