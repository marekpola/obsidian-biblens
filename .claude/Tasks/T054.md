# Task 54 – Translation priority/abbreviation: settings UI

Status: **Next**
Source: docs/SPEC.md § Translation Display Priority and Abbreviation Settings

## Goal

Update the **Installed translations** list in Settings to show an abbreviation text field and a priority dropdown per row; implement drag-and-drop reordering; remove the "Set as default" button. Persists changes to `translationOrder` and `translationAbbreviations`.

## Scope

- `src/settingsTab.ts` — `renderInstalledTranslations`:
  - Remove "Set as default" button.
  - Add abbreviation text field per row: pre-filled from `settings.translationAbbreviations[id]` (fallback to `id`). Soft-limit: visually flag when length > 3. On change: update `settings.translationAbbreviations[id]`, save.
  - Add priority dropdown per row: options are `1 … n` (n = number of installed translations) plus `-`. Current value from `settings.translationOrder[id]` (null → `-`). On change: renumber other entries to keep sequence contiguous with no gaps, reorder the list display accordingly (numbered rows at top by priority; `-` rows below). Save settings and re-render section.
  - Drag-and-drop using HTML5 native drag API (`draggable="true"`, `dragstart`/`dragover`/`drop` events registered via `registerDomEvent` pattern or direct DOM since these are scoped to the settings modal): reorder rows, reassign priority numbers, save settings.

Row layout (left to right): `[abbreviation field] [priority dropdown] [Delete button]`

Out of scope: Multi-translation loading (T055), insert command changes (T057).

## Definition of Done

- `npm run ci` passes.
- Abbreviation field pre-filled; changes saved; persisted across plugin reload.
- Priority dropdown: changing one entry renumbers others; list reorders.
- Drag-and-drop reorders rows and updates priority numbers.
- "Set as default" button absent from translation rows.
- `-` translations remain below all numbered ones after any reorder.
