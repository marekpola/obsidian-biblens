# Task 55 – Multi-translation data loading

Status: **Next**
Source: docs/SPEC.md § Multi-Translation Hover Pop-up
Decision: docs/DECISIONS.md § D032

## Goal

Extend `main.ts` to load and cache `TranslationData` for all priority-numbered translations in parallel. Expose the ordered active-translation list to all consumers via `getActiveTranslations` from `src/translationOrder.ts`.

## Scope

- `src/main.ts`
  - Replace single `translationData: TranslationData` field (or the temporary `allTranslationData` stub from T053) with `allTranslationData: Record<string, TranslationData>` — keyed by translation id; holds data for all priority-numbered translations.
  - `reloadAllTranslations()` — loads all priority-numbered translations in parallel via `Promise.all([...ids.map(id => loadTranslation(...))])`, then updates `allTranslationData` in-place; dispatches updated scanner/tooltip extension state as needed.
  - On `onload()`: call `reloadAllTranslations()` after migration and settings are ready.
  - Derive the ordered consumer list via `getActiveTranslations(this.settings, this.allTranslationData)` (from `src/translationOrder.ts`) and pass it to:
    - `refTooltipExtension` (updated signature in T056)
    - `insertAfterLastRefCommand` and `replaceLastRefWithQuoteCommand` (updated signatures in T057)
    - Reading View hover builder (used in T056)
  - Remove the single-translation `reloadTranslation()` method (replaced entirely by `reloadAllTranslations()`).
  - All existing call sites that triggered `reloadTranslation()` (e.g. settings save callbacks in `settingsTab.ts`) are updated to call `reloadAllTranslations()`.

- `src/settingsTab.ts`
  - Any existing call to `plugin.reloadTranslation()` replaced by `plugin.reloadAllTranslations()`.

Out of scope: DOM/layout changes for multi-translation display (T056), insert command text output (T057).

## Definition of Done

- `npm run ci` passes.
- Single priority-numbered translation: behaviour identical to v1.0 (single `TranslationData` entry in `allTranslationData`; consumer list has one item).
- Two priority-numbered translations: both loaded at startup; both present in `allTranslationData`.
- After settings save (priority change / new download): `reloadAllTranslations()` called; updated map reflected immediately without plugin restart.
- No reference to `reloadTranslation()` (single-translation version) remains in codebase.
