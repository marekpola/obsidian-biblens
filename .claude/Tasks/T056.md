# Task 56 – Multi-translation verse DOM

Status: **Next**
Source: docs/SPEC.md § Multi-Translation Hover Pop-up

## Goal

Extend the verse DOM builder and hover/tooltip integration to display multiple active translations — stacked (single verse) or paged (multi-verse) — while preserving the existing single-translation path unchanged.

## Scope

- `src/ui/verseDOM.ts`:
  - Keep `buildVerseDOM(entries: VerseEntry[]): HTMLElement` unchanged (single-translation path).
  - Add `buildMultiTranslationDOM(blocks: { abbreviation: string; entries: VerseEntry[] }[], refFormat?: ReferenceFormatRules): HTMLElement`:
    - **Single verse / single-chapter ref** (each `entries` array has one entry or is from a chapter-only ref): stacked layout — each block rendered as `abbr label text`, separated by `<hr>` elements.
    - **Multi-verse / chapter-range ref** (any `entries` array has more than one entry): paged layout — one `<div>` per translation; previous/next buttons switch visible page; page heading shows translation abbreviation; page state initialised to first translation.
    - If a block's `entries` is empty: show abbreviation only, no verse text, no error.
    - All DOM construction via `createElement`/`textContent`; no `innerHTML`.

- `src/editor/refTooltip.ts`:
  - Update factory signature to accept ordered active translations list (from T055).
  - When list has 1 entry: call existing `buildVerseDOM` (no change).
  - When list has 2+ entries: call `buildMultiTranslationDOM`.
  - Note: if paged navigation arrows are not reachable in CM6 `hoverTooltip` (mouse-leave dismissal), fall back to stacked layout for multi-verse refs in the editor tooltip.

- `src/main.ts`:
  - Reading View hover: pass ordered translations list to `getVerses` for each active translation; assemble `blocks` array; call `buildMultiTranslationDOM` when multiple active translations; call `buildVerseDOM` for single.

Out of scope: Settings data (T053/T054), data loading (T055), insert commands (T057).

## Definition of Done

- `npm run ci` passes.
- Single active translation: hover identical to v1.0.
- Two active translations, single verse ref: stacked pop-up with abbreviation prefix and `<hr>` separator.
- Two active translations, multi-verse ref: paged pop-up with prev/next navigation; page heading; resets to first page on re-open.
- Translation missing a verse: shows abbreviation only, no error text.
- No `innerHTML` used in new DOM code.
- docs/TESTPLAN.md updated with multi-translation hover test cases.
