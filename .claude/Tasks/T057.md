# Task 57 – Multi-translation insert commands

Status: **Next**
Source: docs/SPEC.md § Insert Commands — Multi-Translation Behaviour
Decision: docs/DECISIONS.md § D033

## Goal

Update `insertAfterLastRefCommand` and `replaceLastRefWithQuoteCommand` in `insertVerse.ts` to accept the ordered active-translations list (from T055) and produce multi-translation output.

## Scope

- `src/editor/insertVerse.ts` (pure module — no Obsidian imports):
  - **`insertAfterLastRefCommand`** new signature:
    ```ts
    insertAfterLastRefCommand(
      scanner: RefScanner,
      activeTranslations: { id: string; abbreviation: string; data: TranslationData }[],
      refFormat?: ReferenceFormatRules
    ): Command
    ```
    - Reads only `activeTranslations[0]` (priority-1 translation).
    - Inserted text: ` — {abbreviation} {verse text}` (abbreviation prefix added; changes output vs v1.0 even for single-translation case — this is intentional per D033).
    - No-op when `activeTranslations` is empty or `getVerses` returns no entries.

  - **`replaceLastRefWithQuoteCommand`** new signature:
    ```ts
    replaceLastRefWithQuoteCommand(
      scanner: RefScanner,
      activeTranslations: { id: string; abbreviation: string; data: TranslationData }[],
      refFormat?: ReferenceFormatRules
    ): Command
    ```
    - Iterates all entries in `activeTranslations` in order.
    - For each entry: calls `getVerses(entry.data, ref, refFormat)`; if result is non-empty, appends `> {abbreviation} {label} {verse text}` lines (one line per entry if single verse, or one line per verse for multi-verse).
    - Translations with no verse text for the reference are silently omitted.
    - No-op when `activeTranslations` is empty or all translations return no entries.

- `src/main.ts`:
  - Both `addCommand` registrations updated to pass `getActiveTranslations(this.settings, this.allTranslationData)` as the `activeTranslations` argument.

Out of scope: Hover/tooltip DOM changes (T056).

## Definition of Done

- `npm run ci` passes.
- `Insert verse after previous reference`: inserts `— {verse text}` (no abbreviation) using priority-1 translation.
- `Replace previous reference with quote`: single active translation → one `> abbr ref text` block; two active translations → two `> abbr ref text` blocks in priority order; missing verse for one translation → that translation omitted.
- `insertVerse.ts` has no `obsidian` import.
- docs/TESTPLAN.md updated with multi-translation insert test cases.
