# Task 58 – Insert book abbreviation command

Status: **Next**
Source: docs/SPEC.md § Insert Book Abbreviation

## Goal

Add command `BibLens: Insert book abbreviation` that opens a filterable modal listing canonical abbreviations from the active reference format pack; selecting one inserts it at the cursor.

## Scope

- `src/ui/bookAbbreviationModal.ts` (new module — may import from `obsidian`; see ARCHITECTURE.md § Boundaries):
  - `class BookAbbreviationModal extends SuggestModal<string>`
  - Constructor: `(app: App, formatBooks: Record<string, string>, onChoose: (abbr: string) => void)`
    - `formatBooks`: `ReferenceFormatRules.books` map (USFM id → canonical abbreviation) from the active format pack; pass `{}` when no pack is active.
  - `getSuggestions(query: string): string[]`:
    - When `formatBooks` is non-empty: return abbreviation values filtered by case-insensitive substring match against `query`.
    - When `formatBooks` is empty (no format pack active): return USFM ids from `BOOK_IDS` (all 66 canonical ids from `books.ts`), filtered by substring match.
  - `renderSuggestion(abbr: string, el: HTMLElement)`: `el.textContent = abbr` — no `innerHTML`.
  - `onChooseSuggestion(abbr: string)`: calls `onChoose(abbr)`.

- `src/main.ts`:
  - Register command: `{ id: 'biblens-insert-book-abbreviation', name: 'Insert book abbreviation' }`
  - Use `checkCallback`: return `true` (checking) / run (not checking) only when `this.app.workspace.getActiveViewOfType(MarkdownView)` is non-null.
  - On execute: open `new BookAbbreviationModal(this.app, this.activeRefFormat?.books ?? {}, (abbr) => { /* CM6 transaction to insert abbr at cursor */ })`.
  - No active editor: show `new Notice('No active editor.')` and return.
  - CM6 insertion: dispatch a transaction via `view.dispatch({ changes: { from: cursor, insert: abbr } })` — same pattern as existing insert commands.

## Definition of Done

- `npm run ci` passes.
- Command appears in palette as "BibLens: Insert book abbreviation".
- Modal lists abbreviations from the active reference format pack; typing filters the list by substring.
- Selecting an entry inserts the abbreviation at the cursor position in the active editor.
- Invoked outside an editing context (Reading View, no open note): Notice shown, no error thrown.
- No active reference format pack: modal falls back to USFM ids.
- No `innerHTML` anywhere in `bookAbbreviationModal.ts`.
- docs/TESTPLAN.md updated with book abbreviation insert test cases.
