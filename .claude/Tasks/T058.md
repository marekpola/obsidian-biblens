# Task 58 – Insert book abbreviation command

Status: **Next**
Source: docs/SPEC.md § Insert Book Abbreviation

## Goal

Add command `BibLens: Insert book abbreviation` that opens a filterable modal listing canonical abbreviations from the active reference format pack; selecting one inserts it at the cursor.

## Scope

- `src/ui/bookAbbreviationModal.ts` (new file):
  - Class `BookAbbreviationModal extends SuggestModal<string>` (Obsidian built-in).
  - Constructor accepts `app: App`, `formatBooks: Record<string, string>` (USFM → abbreviation map from `ReferenceFormatRules.books`), and a callback `onChoose: (abbr: string) => void`.
  - `getSuggestions(query: string): string[]`: returns abbreviation values from `formatBooks` filtered by `query` (case-insensitive substring match); if `formatBooks` is empty, returns USFM keys (66 canonical ids) as fallback.
  - `renderSuggestion(abbr: string, el: HTMLElement)`: sets `el.textContent = abbr`.
  - `onChooseSuggestion(abbr: string)`: calls `onChoose(abbr)`.
  - No `innerHTML`.

- `src/main.ts`:
  - Register command id `biblens-insert-book-abbreviation`, name `"Insert book abbreviation"`.
  - `checkCallback`: active when an editing context exists (`this.app.workspace.getActiveViewOfType(MarkdownView)` is non-null, or equivalent).
  - When invoked: open `BookAbbreviationModal`; in `onChoose`, dispatch a CM6 transaction to insert the abbreviation at the current cursor position.
  - When no active editor: show `new Notice("No active editor.")`.

Module boundary: `bookAbbreviationModal.ts` may import from `obsidian` (it extends `SuggestModal`).

## Definition of Done

- `npm run ci` passes.
- Command appears in palette as "BibLens: Insert book abbreviation".
- Modal lists abbreviations from active format pack; filters by typed query.
- Selecting inserts abbreviation at cursor in editing view.
- No active editor: Notice shown, no error.
- No format pack active: modal falls back to USFM ids.
- docs/TESTPLAN.md updated with book abbreviation insert test cases.
